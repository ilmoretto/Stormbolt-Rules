# Site público do Storm City

Estrutura estática pronta para GitHub Pages.

## Arquivos

- `index.html`: página inicial.
- `termos-de-servico.html`: Termos de Serviço.
- `privacy-policy.html`: Política de Privacidade.
- `regras-de-uso.html`: Regras de Uso.
- `styles.css`: estilos compartilhados.
- `.nojekyll`: evita processamento desnecessário do Jekyll.

## Publicação

Copie todo o conteúdo desta pasta para a raiz do repositório público e ative `Settings` > `Pages` > `Deploy from a branch` > `main` > `/ (root)`.

Ou copie os arquivos para a pasta `/docs` e selecione `main` > `/docs`.

Não copie arquivos `.env`, credenciais, migrations, dados de jogadores ou código operacional para este site público.
