# Documentação pública do Storm City

Esta pasta é uma exportação independente dos documentos que podem ser copiados para um repositório público ou publicados via GitHub Pages.

## Conteúdo

- [Termos de Serviço](termos-de-servico.md)
- [Política de Privacidade](privacy-policy.md)
- [Regras de Uso](regras-de-uso.md)

## Publicação no GitHub Pages

1. Copie todo o conteúdo desta pasta para a raiz de um repositório público separado ou para a pasta `/docs` do repositório público.
2. No GitHub, abra `Settings` > `Pages`.
3. Selecione `Deploy from a branch`.
4. Escolha a branch `main` e a pasta `/docs`, quando aplicável.
5. Publique o endereço gerado pelo GitHub Pages.

## Antes de publicar

- Confirme os prazos de retenção na Política de Privacidade.
- Faça a revisão jurídica dos documentos.
- Não copie `.env`, tokens, senhas, dados de jogadores ou qualquer arquivo operacional do bot.
- Preserve os links entre os documentos na mesma pasta.
